# Modelo Honda FourTrax 3D

Sube aquí `3d-honda-fourtrax-atv.glb` para que el juego cargue automáticamente el FourTrax original. El GLB optimizado mantiene la geometría del modelo descargado y comprime únicamente la textura para permitir la subida desde GitHub Web (<25 MiB).

Si aún no está el GLB, puedes abrir el juego y pulsar **CARGAR HONDA FOURTRAX 3D** para seleccionar el archivo desde tu dispositivo (se guarda localmente).
